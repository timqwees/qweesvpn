# обновление v4.2.0
- 1. Убрали множества логирований от кассы, привели логи об оплате клинта в понятный читаемый вид.
- 2. Решена проблема смещения блоков в админ панели.
- 3. Добавлен новый раздел управление реферальной системой.
- 4. Решена проблема реферальной архитектуры перевод в SOLID, расширение возможностей:
- 4.1. Пригашенные получают : +3 дня к к купленной подписки, так же скидку 10% на N количество продлений.
- 4.2. Пригласитель получает +3 дня за приглашение и 5% дней от покупки каждого приглашенного N количество раз (не бесконечно).
- 4.3. Скидка приглашённого — счётчик на N покупок (`discount_uses` у пользователя, остаток виден в кабинете); разовая = 1. Мёртвый `bonus_percent` вычищен отовсюду (схемы, Client, кабинет, переводы).
- 4.4. Таблица `qwees_refer` оживлена: пишется каждая активация (`takes_left` — остаток снятий % с этого приглашённого), старые привязки дотягиваются бэкфиллом, старая структура мигрирует сама.
- 4.5. Админка `/admin/database`: починен вывод пустых таблиц SQLite (`getColumns` через `pragma_table_info`), у `qwees_subscriptions` колонка `email` через JOIN, у `qwees_users` колонка `status` через JOIN (бейджи по `USER_STATUSES`).
- 4.6. Пути `Groups::$file` и `Gifts::$file` переведены на абсолютные через `__DIR__` — больше не плодятся копии `setting/...` при чужом CWD.
- 5. Переменование WRK -> WLC (решение проблем перехватата только административных действий в свой чат)
- 6. Сессии: срок пользователя — неделя (админ — сутки), хранилища разделены (выход из профиля не трогает админку и наоборот); удалённый пользователь вылетает при следующем запросе (проверка в `Auth::auth()`).
- 7. ACID для базы: `Database::transaction()` с ретраями deadlock/busy и вложенностью; SQLite — WAL/busy_timeout; мульти-записи (регистрация, активация рефералки, касса, удаление юзера) — одним коммитом; страховка висячих транзакций на persistent-соединениях.
- 8. Чат: починен lost update `chats.json` — фото больше не исчезают при параллельном опросе (атомарное чтение-изменение-запись под `flock`, id через `max+1`).
- 9. Мобильный чат поддержки — отдельной секцией через кнопку в шапке слева (без новой страницы, ленивый рендер как остальные).
- 10. Страница оплаты: зачёркнутая старая цена + пилюля «Применена реферальная скидка −N%» (десктоп, мобайл, финальный экран).
- 11. Кабинет: блок «Кто что получает» с живыми цифрами из настроек рефералки.
- 12. Триал vs рефералка vs покупка: триал добавляется поверх остатка (бонусные дни не сгорают), запрет поверх paid/`pending_vpn`; покупка поверх триала/бонуса не блокируется, остаток переносится (`Kassa::carryFromRow()`).
- 13. Админка: чинен `update()` (всегда возвращал false — не сохранялось/кидало на таблицу); удаление пользователей с чисткой подписок и истории; колонка «статус подписки» после id; email после status.
- 14. Админ-вёрстка: секции на `flex`-каркасе как на главной, `min-w-0` против распирания, длинные ссылки подписок с `break-all`.
- 15. Калькулятор ROI в админке (право `roi`, раздел в «Аналитике»): выручка 30 дней, расходы из `costs.json`, прибыль, ROI%, маржа, точка безубыточности; плюс чинен `data-section` заглушки Графиков.
- 16. WLC убран из общих логов (видны только в «Ролях»);.
- 17. «Прибыль по тарифам»: вместо сырых URL подписок — корзины Оплаченные/Пробные/Бонусные/Ожидающие (пустая таблица честно показывает «Нет данных»).
- 18. Красный бейдж непрочитанных в меню «Чат» (`getTotalUnread()` + живое обновление опросом раз в 20 сек).
- 19. Отправка фото: нормализация в JPEG на клиенте (чинит HEIC с айфонов и файлы >5МБ), видимые ошибки вместо тихого пропадания; сервер принимает `heic/heif`.
