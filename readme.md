# обновление v4.0.0

- 1. Мульти-серверность: создан центральный класс выбора сервера `setting/Route/Function/Controllers/Server/Network.php` — все данные серверов (панель 3x-ui, подписка, inbound, VLESS хост) теперь хранятся в одном реестре `SERVERS`, а не в `.env`
- 2. Автоопределение сервера клиента: код сервера берётся из субдомена его подписки в базе (`nl.qweesvpn.online` -> Нидерланды), без подписки клиент работает на сервере по умолчанию
- 3. Смена сервера пользователем: метод `Network::switchServer()` переносит клиента на новую панель 3x-ui с сохранением остатка дней подписки и перезаписью подписки в БД (меняется субдомен)
- 4. Выбор сервера в разделе профиль: radio scroll список (флаг + страна + метка текущего) на ПК и мобильной версии, показывается при активной подписке
- 5. Новый API эндпоинт `POST /api/server/switch` для смены сервера из профиля
- 6. Все сервисы переведены на реестр серверов: Xray (выдача/продление/удаление ключей), Kassa (URL подписки), AdminXray (админ-выдача), Location (флаг локации), VpnStatus (пинг/IP/локация)
- 7. Подготовка к добавлению новых локаций: новый сервер = одна запись в массиве `SERVERS` по образцу `'nl'`, автоматически появляется в списке выбора профиля
- 8. Cookie-сессии панелей 3x-ui кэшируются отдельно и сбрасываются при смене сервера
- 9. В ответ выдачи ключа `client_data` добавлены код сервера и URL подписки на этом сервере
- 10. Удалён неиспользуемый cron-роут `/api/cron/xray-cleanup` (истёкшие ключи удаляются индивидуально при заходе пользователя), восстановлен повреждённый блок роута
- 11. Исправлен баг смены сервера: клиент создавался на старой панели — теперь порядок шагов гарантирует создание на новой панели с откатом подписки в БД при ошибке
- 12. Добавлен Cache Busting на файлы (все верси файлов будут в текущем виде у всех пользователей)
- 13. Исправлена проблема невидимости 4 цифры в поле ввода кода.
- 14. Исправлен баг с возвратом на окно ввода почты при системе устройств автоставки кода iPhone
