# Список прав админ-панели

Константа `Admin::FULL_PERMISSIONS` (и `Admin::PERMS`) определяет доступ к секциям панели и тумблерам в таблице рабочих.

| Право | Что дает доступ | Где используется |
| :--- | :--- | :--- |
| **main** | Главная страница админки | Сайдбар, шапка index.php |
| **price** | Настройка тарифов/цен | Сайдбар → цена, index.php (секция цен) |
| **give** | Выдача подписок | Сайдбар → выдача, index.php (секция выдачи) |
| **reduce** | Изъятие подписок | Сайдбар → изъятие, index.php (секция изъятия) |
| **database** | База данных / таблицы | Сайдбар → База данных, index.php (секция БД), database.php (заглушка 403) |
| **charts** | Графики и аналитика | Сайдбар → Графики, index.php (секция графиков) |
| **logs** | Журнал логов сервера | Сайдбар → Логи, index.php (секция логов), index.php (блок логов рабочих) |
| **add_user** | Добавление новых пользователей | Сайдбар → Добавить пользователя, index.php (секция добавления), роут `/admin/addUser` |
| **roles** | Управление ролями и правами | Сайдбар → Роли и права, index.php (секция roles), роут `/admin/roles` (POST-запросы) |

---

### Иерархия ролей (Admin::ROLES)

| Роль | Числовой уровень | Описание |
| :--- | :---: | :--- |
| **manager** | 1 | Базовая роль, минимум прав |
| **moderator** | 1 | То же уровень, что и manager |
| **admin** | 2 | Выше всех — доступ ко всем правам (`FULL_PERMISSIONS`) |

> **Новая роль** — добавь одну строку в константу `Admin::ROLES`, например `'support' => 1`, и она появится в селектах найма/смены роли. Права даются тумблерами через `Admin::PERMS`.
